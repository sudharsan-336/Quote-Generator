# 💬 Quote Generator
## Overview
The **Quote Generator** is a simple web-based application that displays random inspirational quotes instantly using an API. Users can generate new quotes with a single click and share them directly on Twitter/X. The project features a clean and modern user interface for a smooth user experience.

## Features
### Random Quote Generation
- Fetches random quotes from an online API
- Displays:
  - Quote text
  - Author name
- Generates a new quote instantly on button click

### Tweet Quote
- Share quotes directly on Twitter/X
- Opens tweet window with quote and author automatically added

### User Interface
- Clean and modern design
- Responsive layout
- Smooth and user-friendly UI

## Technologies Used
- **HTML5** → Structure of the application  
- **CSS3** → Styling and responsive design  
- **JavaScript** → API fetching and interactivity  

## Project Structure
- **index.html** → Main structure of the application  
- **style.css** → Styling and layout design  
- **script.js** → Quote fetching and tweet functionality  
- **images/** → Contains logo and Twitter icon images  

## API Used
- Random Quote API:  
 👉 https://dummyjson.com/quotes/random

## Software Requirements
- Any modern web browser (Chrome, Edge, Firefox, etc.)
- Code editor (**VS Code recommended**)

## How It Works
1. The application loads a random quote from the API
2. The quote and author are displayed on the screen
3. Click the **New Quote** button to generate another quote
4. Click the **Tweet** button to share the quote on Twitter/X

## How to Run the Project

1. Download or clone the repository
2. Open the project folder in VS Code
3. Run **index.html** in any browser (**Chrome recommended**)
